## ✦ Getting Started

### Prerequisites

- **Node.js**: v18 or later
- **npm** or preferred package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/Krishil1108/philosophical-coaching-mpcard.git

# Navigate to project directory
cd philosophical-coaching-mpcard

# Install dependencies
npm install
```

### Environment Configuration

Create a `.env.local` file in the root directory and configure your credentials:

```env
NEXT_PUBLIC_SANITY_PROJECT_ID=your_project_id
NEXT_PUBLIC_SANITY_DATASET=production
NEXT_PUBLIC_SANITY_API_VERSION=2024-01-01
```

### Development

Start the local development server:

```bash
npm run dev
```

Visit [`http://localhost:3000`](http://localhost:3000) to view the application.
